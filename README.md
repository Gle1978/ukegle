# UkeGle

เว็บแอปหัดเล่นอูคูเลเลสำหรับผู้เริ่มต้น ใช้คอร์ดง่าย 13 คอร์ด พร้อมเพลงย้อนยุคไทยและสากล

ไฟล์ในโฟลเดอร์นี้
- index.html ตัวแอปทั้งหมด (ข้อมูลคอร์ดและเพลงอยู่ในตัวแปร CHORDS และ SONGS)
- manifest.webmanifest, sw.js, icon-192.png, icon-512.png ทำให้ติดตั้งลงหน้าจอมือถือและเปิดแบบออฟไลน์ได้

การเพิ่มเนื้อเพลงเมื่อได้รับอนุญาต: ใส่ฟิลด์ lyrics ให้เพลงนั้นใน SONGS โดยใช้รูปแบบ [คอร์ด] หน้าคำที่ต้องเปลี่ยนคอร์ด เช่น
